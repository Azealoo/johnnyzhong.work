# johnnyzhong.work

Source for [johnnyzhong.work](https://johnnyzhong.work), Johnny Zhong's personal website.

A single static page (`index.html`) with self-hosted Archivo and JetBrains Mono fonts (SIL Open Font License), served by GitHub Pages from the `main` branch. `CNAME` sets the custom domain.

To edit: change `index.html`, commit and push to `main`. GitHub Pages redeploys in about a minute.
